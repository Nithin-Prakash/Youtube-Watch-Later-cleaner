# Privacy Policy for Watch Later Cleaner

Last Updated: June 2026

## Overview

Watch Later Cleaner is committed to protecting user privacy.

The extension is designed to operate entirely within the user's browser and does not collect, store, transmit, share, or sell personal information.

## Information We Collect

Watch Later Cleaner does not collect any of the following:

- Personal information
- Names
- Email addresses
- Account credentials
- YouTube account information
- Browsing history
- Location information
- Analytics data
- Usage statistics
- Device identifiers

## How the Extension Works

The extension operates only on the YouTube Watch Later playlist page when initiated by the user.

To perform playlist management actions, the extension temporarily interacts with page elements that are already visible within the user's browser.

No playlist information is transmitted outside the user's device.

## Data Storage

The extension may store user preferences locally within the browser using Chrome Extension Storage APIs.

Examples may include:

- Extension settings
- User interface preferences
- Cleanup progress information

This information remains on the user's device and is never transmitted to external servers.

## Data Sharing

Watch Later Cleaner:

- Does not transmit data to external servers
- Does not sell user information
- Does not share user information with third parties
- Does not use advertising networks
- Does not use analytics platforms
- Does not use tracking technologies

## Remote Code

Watch Later Cleaner uses only code bundled with the extension package.

The extension does not download, execute, or rely upon remotely hosted code for extension functionality.

## Third-Party Services

The extension does not communicate with any third-party services for its operation.

## Security

All extension functionality executes locally within the user's browser environment.

No user information is transmitted or stored externally.

## Changes to This Privacy Policy

This Privacy Policy may be updated from time to time.

Any changes will be reflected by updating the "Last Updated" date at the top of this document.
